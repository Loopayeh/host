# PS4 Host — ps4.loopayeh.ir

کالکشن هاست‌های جیلبریک PlayStation 4 (کپی از مجموعه P30DAY).

## نحوه استفاده

در مرورگر PS4 آدرس زیر را باز کنید:

```
http://ps4.loopayeh.ir/
```

یا با HTTPS:

```
https://ps4.loopayeh.ir/
```

سپس بر اساس فریمور کنسول یکی از کالکشن‌ها را انتخاب کنید (5.05 تا 13.52).

## ساختار

- `index.html` — صفحه اصلی و انتخاب فریمور
- `505/`, `672/`, `702/`, `755/`, `9.00/` — کالکشن هر فریمور
- `5.05-13.52/`, `6.00-11.02/`, `ps4jb-Feyzee-AIO/`, `PSFree/`, ... — هاست‌های کامل
- `restore/`, `restore-t/` — راهنماهای نصب/ریستور

## اجرای محلی

```bash
python -m http.server 8080
```

سپس `http://localhost:8080/`

## دامنه

GitHub Pages با دامنه سفارشی `ps4.loopayeh.ir` (فایل `CNAME`).
